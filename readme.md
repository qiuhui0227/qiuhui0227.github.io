# OASIS | Qiuhui & Yan 专属情侣空间

> 秩序美学与温润情调的私属双人星系。基于纯静态 GitHub Pages 部署，集成客厅与卧室双模门禁、早中晚共享时刻表看板、一本一本的岁月相簿与纯前端无损简历编辑器。

---

## 🌟 核心特色与功能模块

### 1. 🚪 客厅与卧室双模门禁系统
- **🛏️ 卧室模式（主人特权）**
  - **默认初始密码**：`admin`
  - 解锁所有私密相册、全量时刻表安排、简历编辑器与后台安全配置。
  - 在后台控制中心可随时修改主人密码。
- **🛋️ 客厅模式（来宾受限访问）**
  - **默认体验密码**：`guest888`
  - 仅能翻阅主人标记为“客厅开放”的相簿和公开时刻事项。
  - **使用次数限制**：支持配置最大使用次数（如 20 次，扣完即止）。
  - **有效期保护**：支持设定过期日期，超期自动失效。
  - 主人随时可在后台一键重置次数、修改密码与有效期。

### 2. 📅 早中晚共享时刻表（实验室预约看板美学）
- **时段划分**：
  - 🌅 **晨光 · 上午时段 (08:00 - 12:00)**
  - ☀️ **专注 · 午后时光 (12:00 - 18:00)**
  - 🌙 **漫步 · 暮色夜间 (18:00 - 24:00)**
- **参加人专属标识**：
  - 👦 `Yan`（王琰 - 沉静蔚蓝）
  - 👧 `Qiuhui`（秋慧 - 温柔粉晶）
  - 👫 `Both`（共同参加 - 双人紫罗兰专属光泽）
- **状态管理**：待进行、进行中、已打卡完成。
- **日期导航**：支持前一天/后一天切换、日历选择器与一键“回到今天”。

### 3. 📖 岁月相簿与照片墙（一本一本 + 自主压缩上传）
- **相簿一本一本**：拥有相册封面、标题寄语、照片数量与客厅/卧室权限徽章。
- **自主压缩上传**：
  - 纯前端 Canvas 视网膜轻量压缩引擎：将数兆高清单反/手机原图无损转为高质量 WebP/JPEG（约 80KB~150KB），既秒开又省空间。
  - 支持多图同时上传，数据通过浏览器底层 `IndexedDB` 持久化存储。
- **沉浸式灯箱（Lightbox）**：点击照片放大全屏浏览，支持键盘左右键翻页。

### 4. 🌟 人生ToDo · 星光愿景与心愿清单 (Bucket List)
- **浪漫奔赴与终身追求**：涵盖「两人共同约定」、「杜秋慧专属」与「王岩专属」三大维度，分类覆盖环游世界、浪漫约定、奇趣体验、精进成长、暖心安家等板块。
- **仪式感圆梦打卡**：支持记录圆梦达成日期、足迹地点、回忆感言与纪念瞬间照片，点亮专属「DREAM ACHIEVED」荣耀印章。
- **内置愿望灵感库**：精选 60+ 浪漫情侣/环球旅行/极致体验/学业高光灵感，支持一键采纳填入。
- **多维度筛选与实时进度看板**：支持实时统计完成率、待办/筹备中/已圆梦分类筛选与即时搜索。
- **导出与云端双向同步**：支持一键导出 Markdown 纪念文档，多端秒级双向无缝同步。

### 5. 📄 简历编辑器（A4 高保真 + 多格式导出）
- **双向实时渲染**：左侧结构化表单修改，右侧标准 A4 白板实时排版渲染。
- **多端自适应**：电脑端左右分屏实时对照；手机端提供【编辑】与【预览】一键切换。
- **多格式导出**：
  - **下载 A4 PDF**：调用高保真矢量打印引擎，精准契合 A4 物理比例，边距与分页完美保护。
  - **下载 Word 文档**：纯前端生成标准的 `.doc` 文档，Microsoft Word 与 WPS Office 原生兼容。

### 6. 📱 全设备响应式适配
- **电脑端 (PC >= 1024px)**：三列时刻看板、多列相簿、左右分屏简历。
- **平板端 (Pad 768px ~ 1023px)**：双列排布，大尺寸触控优化。
- **手机端 (Mobile < 768px)**：单列信息流、底部悬浮导航条、手机端专用 Tab 切换。

## 🚀 本地预览与体验

直接用浏览器打开项目根目录下的 [`index.html`](./index.html) 即可体验全部功能。

或使用任意本地静态服务器：
```bash
# Python
python -m http.server 8080

# 或 Node.js
npx serve .
```
